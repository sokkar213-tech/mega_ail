# Mega AI — النسخة الأولية

واجهة عربية متجاوبة بالبنفسجي، مع خادم Node.js لمسارات الدردشة وتوليد الصور وتلخيص ملفات PDF، بالإضافة إلى كتابة المحتوى والبرمجة ومفاهيم اللوجوهات وسيناريوهات الفيديو.

## المتطلبات
- Node.js 18 أو أحدث
- اتصال إنترنت
- مفتاح API من OpenAI مع فوترة/رصيد متاح. اشتراك ChatGPT لا يتضمن تلقائيًا رصيد API.

## التشغيل على الكمبيوتر
1. فك ضغط الملف.
2. ثبّت Node.js من الموقع الرسمي: https://nodejs.org/
3. افتح Terminal أو موجه الأوامر داخل مجلد `mega-ai`.
4. نفّذ:
   ```bash
   npm install
   ```
5. انسخ `.env.example` إلى ملف اسمه `.env`، وضع مفتاح API الخاص بك مكان القيمة التجريبية:
   ```env
   OPENAI_API_KEY=your_secret_key
   PORT=3000
   ```
   لا ترفع `.env` إلى GitHub ولا تشارك المفتاح مع أي شخص.
6. شغّل:
   ```bash
   npm start
   ```
7. افتح `http://localhost:3000`.

## حالة الخدمات
- الدردشة وكتابة المحتوى والبرمجة وأفكار الشعارات: تستخدم نموذج محادثة عبر API.
- الصور: تستخدم `gpt-image-1` إذا كان متاحًا لحساب API.
- PDF: يستخرج النص من ملفات PDF النصية ثم يلخصه؛ الملفات الممسوحة ضوئيًا تحتاج OCR غير مضاف بعد.
- الفيديو: يولّد سيناريو نصيًا فقط. لتوليد ملف فيديو حقيقي، اربط مزود فيديو يدعم API بعد اختيار المزود ومراجعة التكلفة.

## قبل النشر العام
هذه نسخة بداية وليست جاهزة للإطلاق التجاري بعد. أضف على الأقل:
- تسجيل دخول آمن، وتحديد معدل الطلبات، وحدود استخدام لكل مستخدم.
- صفحة خصوصية وشروط استخدام وحذف آمن للملفات.
- حماية من إساءة الاستخدام ومراقبة التكلفة.
- عدم حفظ مفاتيح API في الواجهة أو المستودع.
- HTTPS وإعداد متغيرات البيئة على منصة الاستضافة.
